# FocuTime Assets

This directory contains the visual assets for the FocuTime MVP.

## Color Palette
- Primary: Deep Blue (#1A237E)
- Accent: Soft Orange (#FF6F00)
- Premium: Gold (#FFD700)

## Directory Structure
- `icons/`: App icons (1024x1024)
- `splash/`: Splash screen graphics (1024x1536)
- `onboarding/`: Illustrations and icons for onboarding and interest categories
- `placeholders/`: Empty state and suggestion card placeholders
- `premium/`: Visual assets for premium/subscription features

## Files

### Core Brand & UI
- `icons/app_icon_v2.png`: Main app icon (focus shield / clock-checkmark fusion)
- `splash/splash_screen_dark.png`: Dark-themed splash screen

- `placeholders/streak_flame.png`: Streak flame icon

- `placeholders/analytics_dashboard_mockup.png`: UI mockup for the enhanced Distraction Analytics dashboard
